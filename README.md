# EPoBuilds Studios — Official Downloads

## EPo Studio (current version: 1.2.0)

One program for building websites and apps — and turning them into Android
apps — with no subscriptions, no credits, and no meters running.

- **Studio**: visual builder with projects, templates, an AI chat builder,
  and a Publish Center (PWA exports, your own PocketBase backend).
- **Forge — APK Builder**: the APK engine built in. Build direct-install
  APKs, iOS web-app bundles, and Google Play–ready `.aab` bundles signed
  with your own key.

### Install (Windows)

Download `EPoStudio-Setup-1.2.0.zip`, extract it, and run the setup .exe.
The installer is unsigned, so Windows SmartScreen will warn you — click
**More info → Run anyway**. That's expected for independent software that
isn't signed with a paid certificate.

Releases are published on this repo's **Releases** page as they land.
